پاسخ‌های مبتنی بر پایگاه داده

برای اینکه برنامه وب Snippetbox ما واقعاً مفید شود، نیاز داریم جایی برای ذخیره (یا پایدارسازی) داده‌های وارد شده توسط کاربران داشته باشیم و توانایی پرس‌وجو از این مخزن داده به صورت پویا در زمان اجرا را داشته باشیم.

مخازن داده‌های مختلفی وجود دارند که می‌توانیم برای برنامه خود استفاده کنیم — هر کدام با مزایا و معایب مختلف — اما ما پایگاه داده رابطه‌ای محبوب MySQL را انتخاب خواهیم کرد.

توجه: تمام الگوهای کد عمومی در این بخش از کتاب به سایر پایگاه‌های داده مانند PostgreSQL یا SQLite نیز اعمال می‌شوند. اگر در حال دنبال کردن هستید و ترجیح می‌دهید از پایگاه داده دیگری استفاده کنید، می‌توانید، اما من توصیه می‌کنم ابتدا از MySQL استفاده کنید تا احساسی از نحوه کار همه چیز پیدا کنید و سپس به عنوان یک تمرین، پایگاه داده‌ها را پس از اتمام کتاب تغییر دهید.

در این بخش یاد خواهید گرفت که چگونه:

  • نصب یک درایور پایگاه داده به عنوان یک 'واسط' بین MySQL و برنامه Go شما.
  • اتصال به MySQL از برنامه وب خود (به طور خاص، یاد خواهید گرفت که چگونه یک مجموعه از اتصالات قابل استفاده مجدد ایجاد کنید).
  • ایجاد یک بسته models مستقل، به طوری که منطق پایگاه داده شما قابل استفاده مجدد و از برنامه وب شما جدا باشد.
  • استفاده از توابع مناسب در بسته database/sql Go برای اجرای انواع مختلف دستورات SQL، و چگونگی جلوگیری از خطاهای رایج که می‌توانند منجر به اتمام منابع سرور شما شوند.
  • جلوگیری از حملات تزریق SQL با استفاده صحیح از پارامترهای جایگزین.
  • استفاده از تراکنش‌ها، به طوری که بتوانید چندین دستور SQL را در یک عمل اتمی اجرا کنید.
