راه‌اندازی فرم HTML (Setting Up an HTML Form)

اولین قدم، ایجاد یک فرم HTML (HTML Form) است که به کاربران اجازه می‌دهد قطعه‌های کد (Code Snippets) جدید را ارسال کنند. این فرم باید شامل فیلدهای ورودی (Input Fields) برای عنوان، محتوا و مدت زمان انقضا باشد.

یک فایل create.tmpl جدید در دایرکتوری ui/html ایجاد کنید:

واژه‌نامه اصطلاحات فنی

اصطلاح فارسی معادل انگلیسی توضیح
فرم HTML HTML Form ساختار HTML برای جمع‌آوری داده از کاربر
قطعه‌های کد Code Snippets بخش‌های کوچک و مستقل کد
فیلدهای ورودی Input Fields عناصر HTML برای دریافت داده از کاربر
متد POST POST Method روش ارسال داده‌های فرم به سرور
برچسب Label توضیح متنی برای فیلدهای ورودی
ورودی متنی Text Input فیلد ورودی برای متن یک خطی
ناحیه متنی Textarea فیلد ورودی برای متن چند خطی
دکمه رادیویی Radio Button دکمه انتخاب یکی از چند گزینه
دکمه ارسال Submit Button دکمه برای ارسال فرم
قالب Template الگوی HTML برای تولید صفحات پویا
