پیش‌نیازها

دانش پایه

این کتاب برای افرادی طراحی شده که تازه با Go آشنا شده‌اند، اما اگر درک کلی از نحو Go داشته باشید، احتمالاً از مطالعه آن لذت بیشتری خواهید برد. اگر در درک نحو مشکل دارید، کتاب کوچک Go نوشته Karl Seguin یک آموزش عالی است، یا اگر چیزی تعاملی‌تر می‌خواهید، پیشنهاد می‌کنم تور Go را انجام دهید.

همچنین فرض کرده‌ام که درک (بسیار) پایه‌ای از HTML/CSS و SQL دارید و با استفاده از ترمینال (یا خط فرمان برای کاربران ویندوز) آشنا هستید. اگر قبلاً با هر زبان دیگری وب اپلیکیشن ساخته‌اید — خواه Ruby، Python، PHP یا C# — این کتاب برای شما مناسب خواهد بود.

Go 1.23

اطلاعات این کتاب برای آخرین نسخه اصلی Go (نسخه 1.23) صحیح است و اگر می‌خواهید همراه با ساخت اپلیکیشن کدنویسی کنید، باید این نسخه را نصب کنید.

اگر قبلاً Go را نصب کرده‌اید، می‌توانید شماره نسخه را از ترمینال با استفاده از دستور go version بررسی کنید. خروجی باید شبیه این باشد:

اگر نیاز به ارتقای نسخه Go دارید — یا می‌خواهید Go را از ابتدا نصب کنید — لطفاً همین حالا این کار را انجام دهید. دستورالعمل‌های دقیق برای سیستم‌عامل‌های مختلف را می‌توانید در اینجا پیدا کنید:

  • حذف نسخه قدیمی Go
  • نصب Go روی Mac OS X
  • نصب Go روی Windows
  • نصب Go روی Linux

سایر نرم‌افزارها

چند نرم‌افزار دیگر وجود دارد که اگر می‌خواهید به طور کامل همراهی کنید، باید مطمئن شوید روی کامپیوتر شما نصب هستند:

  • ابزار curl برای کار با درخواست‌ها و پاسخ‌های HTTP از ترمینال. روی سیستم‌عامل‌های MacOS و Linux معمولاً از پیش نصب شده است یا در مخازن نرم‌افزاری موجود است. در غیر این صورت، می‌توانید آخرین نسخه را از اینجا دانلود کنید.

  • یک مرورگر وب با ابزارهای توسعه‌دهنده خوب. من در این کتاب از Firefox استفاده می‌کنم، اما Chromium، Chrome یا Microsoft Edge هم کار خواهند کرد.

  • ویرایشگر متن مورد علاقه شما 😊
