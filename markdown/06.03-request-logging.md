# فصل ۶.۳

## ثبت درخواست‌ها

<div dir='rtl'>بیایید در همین راستا ادامه دهیم و یک میان‌افزار برای ثبت درخواست‌های HTTP اضافه کنیم. به طور مشخص، ما از لاگر ساختاریافته‌ای که قبلاً ایجاد کردیم استفاده خواهیم کرد تا آدرس IP کاربر، متد، URI و نسخه HTTP درخواست را ثبت کنیم.</div>

<div dir='rtl'>فایل middleware.go خود را باز کنید و یک متد logRequest() با استفاده از الگوی استاندارد میان‌افزار به شکل زیر ایجاد کنید:</div>

<div dir='ltr'>

**File: cmd/web/middleware.go**

```

package main

...

func (app *application) logRequest(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        var (
            ip     = r.RemoteAddr
            proto  = r.Proto
            method = r.Method
            uri    = r.URL.RequestURI()
        )

        app.logger.Info("received request", "ip", ip, "proto", proto, "method", method, "uri", uri)

        next.ServeHTTP(w, r)
    })
}


```

</div>

<div dir='rtl'>توجه کنید که این بار ما میان‌افزار را به عنوان یک متد روی application پیاده‌سازی می‌کنیم؟</div>

<div dir='rtl'>این کاملاً معتبر است. متد میان‌افزار ما همان امضای قبلی را دارد، اما از آنجایی که یک متد روی application است، به وابستگی‌های هندلر از جمله لاگر ساختاریافته نیز دسترسی دارد.</div>

<div dir='rtl'>حالا بیایید فایل routes.go خود را به‌روزرسانی کنیم تا میان‌افزار logRequest اول و برای تمام درخواست‌ها اجرا شود، به طوری که جریان کنترل (از چپ به راست) به این شکل باشد:</div>

<div dir='ltr'>

**File: cmd/web/routes.go**

```

package main

import "net/http"

func (app *application) routes() http.Handler {
    mux := http.NewServeMux()

    fileServer := http.FileServer(http.Dir("./ui/static/"))
    mux.Handle("GET /static/", http.StripPrefix("/static", fileServer))

    mux.HandleFunc("GET /{$}", app.home)
    mux.HandleFunc("GET /snippet/view/{id}", app.snippetView)
    mux.HandleFunc("GET /snippet/create", app.snippetCreate)
    mux.HandleFunc("POST /snippet/create", app.snippetCreatePost)

    // Wrap the existing chain with the logRequest middleware.
    return app.logRequest(commonHeaders(mux))
}

```

</div>
