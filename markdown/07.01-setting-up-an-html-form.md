# فصل ۷.۱

## راه‌اندازی فرم HTML

<div dir='rtl'>بیایید با ایجاد یک فایل جدید ui/html/pages/create.tmpl برای نگهداری HTML فرم شروع کنیم:</div>

<div dir='rtl'>... و سپس نشانه‌گذاری زیر را با استفاده از همان الگوهای قالب که قبلاً در کتاب استفاده کردیم، اضافه کنید.</div>

<div dir='ltr'>

**File: ui/html/pages/create.tmpl**

```

{{define "title"}}Create a New Snippet{{end}}

{{define "main"}}
<form action='/snippet/create' method='POST'>
    <div>
        <label>Title:</label>
        <input type='text' name='title'>
    </div>
    <div>
        <label>Content:</label>
        <textarea name='content'></textarea>
    </div>
    <div>
        <label>Delete in:</label>
        <input type='radio' name='expires' value='365' checked> One Year
        <input type='radio' name='expires' value='7'> One Week
        <input type='radio' name='expires' value='1'> One Day
    </div>
    <div>
        <input type='submit' value='Publish snippet'>
    </div>
</form>
{{end}}

```

</div>

<div dir='rtl'>تا اینجا چیز خاصی وجود ندارد. قالب main ما شامل یک فرم HTML استاندارد است که سه مقدار فرم را ارسال می‌کند: title، content و expires (تعداد روزهایی که تا انقضای اسنیپت باقی مانده است). تنها نکته‌ای که باید به آن اشاره کرد، ویژگی‌های action و method فرم است - ما این‌ها را طوری تنظیم کرده‌ایم که وقتی فرم ارسال می‌شود، داده‌ها را به URL /snippet/create با متد POST ارسال کند.</div>

<div dir='rtl'>حالا بیایید یک لینک 'ایجاد اسنیپت' جدید به نوار ناوبری برنامه‌مان اضافه کنیم، تا با کلیک کردن روی آن، کاربر به این فرم جدید هدایت شود.</div>

<div dir='ltr'>

{{define "nav"}}

</div>

<div dir='rtl'>و در نهایت، باید هندلر snippetCreate را به‌روزرسانی کنیم تا صفحه جدید ما را به این شکل رندر کند:</div>

<div dir='ltr'>

**File: cmd/web/handlers.go**

```

package main

...

func (app *application) snippetCreate(w http.ResponseWriter, r *http.Request) {
    data := app.newTemplateData(r)

    app.render(w, r, http.StatusOK, "create.tmpl", data)
}

...

```

</div>
