# فصل ۱۲.

# جاسازی فایل

<div dir='rtl'>کتابخانه استاندارد Go شامل یک بسته embed است که امکان جاسازی فایل‌های خارجی در برنامه Go شما را فراهم می‌کند.</div>

<div dir='rtl'>استفاده از بسته embed این فرصت را فراهم می‌کند تا برنامه‌های Go ایجاد کنید که خودکفا هستند و همه چیزهایی که برای اجرا نیاز دارند به عنوان بخشی از فایل اجرایی کامپایل شده دارند. این امر باعث می‌شود که استقرار یا توزیع برنامه وب شما آسان‌تر شود.</div>

<div dir='rtl'>در این بخش از کتاب، برنامه خود را به‌روزرسانی خواهیم کرد تا فایل‌های موجود در دایرکتوری ui را جاسازی کند — با فایل‌های استاتیک CSS، JavaScript و تصویر شروع می‌کنیم و سپس به قالب‌های HTML می‌پردازیم.</div>

<div dir='rtl'>بیایید مستقیماً وارد شویم و توضیح دهیم که چگونه از آن استفاده کنیم.</div>
