## جداسازی مسیرهای برنامه

<div dir='rtl'>در حالی که در حال بازسازی کد خود هستیم، یک تغییر دیگر هم ارزش انجام دادن دارد.</div>

<div dir='rtl'>تابع main() ما شروع به شلوغ شدن کرده است، بنابراین برای اینکه آن را واضح و متمرکز نگه داریم، می‌خواهم اعلان‌های مسیر برای برنامه را به یک فایل مستقل routes.go منتقل کنم، به این صورت:</div>

<div dir='ltr'>

**File:  cmd/web/routes.go**

```

package main

import "net/http"

// The routes() method returns a servemux containing our application routes.
func (app *application) routes() *http.ServeMux {
    mux := http.NewServeMux()

    fileServer := http.FileServer(http.Dir("./ui/static/"))
    mux.Handle("GET /static/", http.StripPrefix("/static", fileServer))

    mux.HandleFunc("GET /{$}", app.home)
    mux.HandleFunc("GET /snippet/view/{id}", app.snippetView)
    mux.HandleFunc("GET /snippet/create", app.snippetCreate)
    mux.HandleFunc("POST /snippet/create", app.snippetCreatePost)

    return mux
}

```

</div>

<div dir='rtl'>سپس می‌توانیم فایل main.go را به این صورت به‌روزرسانی کنیم:</div>

<div dir='ltr'>

**File:  cmd/web/main.go**

```

package main

...

func main() {
    addr := flag.String("addr", ":4000", "HTTP network address")
    flag.Parse()

    logger := slog.New(slog.NewTextHandler(os.Stdout, nil))

    app := &application{
        logger: logger,
    }

    logger.Info("starting server", "addr", *addr)
    
    // Call the new app.routes() method to get the servemux containing our routes,
    // and pass that to http.ListenAndServe().
    err := http.ListenAndServe(*addr, app.routes())
    logger.Error(err.Error())
    os.Exit(1)
}

```

</div>
