# میان‌افزار

<div dir='rtl'>هنگامی که در حال ساخت یک برنامه وب هستید، احتمالاً برخی از قابلیت‌های مشترک وجود دارند که می‌خواهید برای بسیاری (یا حتی همه) درخواست‌های HTTP استفاده کنید. به عنوان مثال، ممکن است بخواهید هر درخواست را ثبت کنید، هر پاسخ را فشرده کنید، یا قبل از ارسال درخواست به پردازشگرهای خود، کش را بررسی کنید.</div>

<div dir='rtl'>یک روش معمول برای سازماندهی این قابلیت‌های مشترک، تنظیم آن‌ها به عنوان میان‌افزار است. این اساساً کدی مستقل است که به طور مستقل قبل یا بعد از پردازشگرهای معمول برنامه شما روی درخواست عمل می‌کند.</div>
