<div dir='rtl'>یک پیام تأیید مانند این باید فقط یک بار برای کاربر نمایش داده شود (بلافاصله پس از ایجاد قطعه) و هیچ کاربر دیگری نباید این پیام را ببیند. اگر مدتی است که برنامه‌نویسی می‌کنید، ممکن است این نوع عملکرد را به عنوان یک پیام فلش یا یک تست بشناسید.</div>

<div dir='rtl'>برای اینکه این کار را انجام دهیم، باید شروع به اشتراک‌گذاری داده‌ها (یا حالت) بین درخواست‌های HTTP حالت دار برای همان کاربر کنیم. رایج‌ترین راه برای انجام این کار پیاده‌سازی یک جلسه برای کاربر است.</div>
