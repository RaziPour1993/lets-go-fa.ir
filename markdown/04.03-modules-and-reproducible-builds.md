# فصل ۴.۳.

## ماژول‌ها و ساخت‌های قابل تکرار

<div dir='rtl'>حالا که درایور MySQL نصب شده است، بیایید نگاهی به فایل go.mod بیندازیم (که در همان ابتدای کتاب آن را ایجاد کردیم). شما باید یک بلوک require با دو خط حاوی مسیر و شماره نسخه دقیق پکیج‌هایی که دانلود کردید را ببینید:</div>

<div dir='ltr'>

**File: go.mod**

```

module snippetbox.letsgofa.net

go 1.23.0

require (
    filippo.io/edwards25519 v1.1.0 // indirect
    github.com/go-sql-driver/mysql v1.8.1 // indirect
)

```

</div>

<div dir='rtl'>این خطوط در go.mod اساساً به دستور Go می‌گویند که دقیقاً از کدام نسخه پکیج باید هنگام اجرای دستوری مانند go run، go test یا go build از دایرکتوری پروژه شما استفاده شود.</div>

<div dir='rtl'>این باعث می‌شود که داشتن چندین پروژه روی یک ماشین که از نسخه‌های مختلف یک پکیج استفاده می‌کنند، آسان شود. برای مثال، این پروژه از نسخه v1.8.1 درایور MySQL استفاده می‌کند، اما شما می‌توانید کد دیگری روی کامپیوتر خود داشته باشید که از نسخه v1.5.0 استفاده می‌کند و این کاملاً قابل قبول است.</div>

<div dir='rtl'>نکته: حاشیه‌نویسی // indirect نشان می‌دهد که یک پکیج مستقیماً در هیچ عبارت import در کد شما ظاهر نمی‌شود. در حال حاضر، ما هنوز هیچ کدی ننوشته‌ایم که واقعاً از پکیج‌های github.com/go-sql-driver/mysql یا filippo.io/edwards25519 استفاده کند، به همین دلیل هر دو به عنوان وابستگی‌های غیرمستقیم علامت‌گذاری شده‌اند. ما این را در فصل بعدی اصلاح خواهیم کرد.</div>

<div dir='rtl'>همچنین خواهید دید که یک فایل جدید به نام go.sum در ریشه دایرکتوری پروژه شما ایجاد شده است.</div>

![04.03-01.png](assets/img/04.03-01.png)

<div dir='rtl'>این فایل go.sum شامل مجموع‌های رمزنگاری شده است که محتوای پکیج‌های مورد نیاز را نشان می‌دهد. اگر آن را باز کنید باید چیزی شبیه به این را ببینید:</div>

<div dir='ltr'>

**File: go.sum**


</div>

<div dir='rtl'>فایل go.sum برای ویرایش دستی طراحی نشده است و معمولاً نیازی به باز کردن آن نخواهید داشت. اما دو عملکرد مفید دارد:</div>

<div dir='rtl'>اگر دستور go mod verify را از ترمینال خود اجرا کنید، این دستور تأیید می‌کند که مجموع‌های رمزنگاری شده پکیج‌های دانلود شده روی ماشین شما با ورودی‌های موجود در go.sum مطابقت دارند، بنابراین می‌توانید مطمئن باشید که تغییر نکرده‌اند.</div>

<div dir='rtl'>اگر شخص دیگری نیاز به دانلود تمام وابستگی‌های پروژه داشته باشد — که می‌تواند با اجرای go mod download انجام دهد — در صورت عدم تطابق بین پکیج‌هایی که دانلود می‌کند و مجموع‌های رمزنگاری شده در فایل، خطایی دریافت خواهد کرد.</div>

#### ارتقای پکیج‌ها
