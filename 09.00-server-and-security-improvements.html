بهبودهای سرور و امنیت

در این بخش از کتاب روی بهبودهای سرور HTTP برنامه خود تمرکز خواهیم کرد. یاد خواهید گرفت:

  • نحوه سفارشی‌سازی تنظیمات سرور با استفاده از نوع http.Server.
  • لاگ خطای سرور چیست و چگونه آن را برای استفاده از لاگر ساختاریافته خود پیکربندی کنیم.
  • نحوه سریع و آسان ایجاد گواهی TLS خودامضا، فقط با استفاده از Go.
  • اصول راه‌اندازی برنامه شما به طوری که همه درخواست‌ها و پاسخ‌ها به صورت امن از طریق HTTPS سرو شوند.
  • برخی تنظیمات منطقی برای تنظیمات پیش‌فرض TLS برای کمک به حفظ امنیت اطلاعات کاربر و عملکرد سریع سرور ما.
  • نحوه تنظیم تایم‌اوت‌های اتصال برای کاهش تأثیر حملات کلاینت کند.
