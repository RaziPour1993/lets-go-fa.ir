بهبودهای سرور و امنیت

در این بخش از کتاب، ما بر روی بهبودهای سرور HTTP برنامه خود تمرکز خواهیم کرد. شما یاد خواهید گرفت:

  • چگونه تنظیمات سرور را با استفاده از نوع http.Server سفارشی کنید.
  • سرور لاگ خطا چیست و چگونه آن را برای استفاده از لاگر ساختاریافته خود پیکربندی کنید.
  • چگونه به سرعت و به راحتی یک گواهی TLS خودامضا ایجاد کنید، تنها با استفاده از Go.
  • اصول راه‌اندازی برنامه خود به گونه‌ای که تمام درخواست‌ها و پاسخ‌ها به صورت امن از طریق HTTPS ارائه شوند.
  • برخی تنظیمات معقول برای تنظیمات پیش‌فرض TLS برای کمک به حفظ امنیت اطلاعات کاربر و عملکرد سریع سرور ما.
  • چگونه زمان‌های انتظار اتصال را تنظیم کنید تا تأثیر حملات مشتری کند را کاهش دهید.
